# SportNest - Client Side

SportNest is a premium platform for booking sports facilities. This project is built using React.js, Tailwind CSS, and Framer Motion to provide a seamless user experience.

## Features
- **Modern UI:** Built with Tailwind CSS and Framer Motion for smooth animations.
- **Dynamic Booking:** Real-time facility browsing and booking system.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop.
- **Secure Auth:** Integrated with AuthContext for user state management.
- **Search & Filter:** Advanced search functionality to find sports venues easily.

## Technologies Used
- React.js
- Tailwind CSS
- Framer Motion
- React Router
- Axios

## How to Run
1. Clone this repository.
2. Run `npm install` to install dependencies.
3. Create a `.env` file and add your Firebase configuration and API URL.
4. Run `npm run dev` to start the project.
